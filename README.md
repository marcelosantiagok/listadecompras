# listadecompras
Lista de compras aplicativo mobile para Android

🛒 Lista de Compras

Um aplicativo simples e prático para ajudar no controle das compras do dia a dia.

O Lista de Compras foi desenvolvido para facilitar a criação e o gerenciamento de listas de compras diretamente pelo celular, permitindo adicionar produtos, controlar o que já foi comprado e manter a organização durante as compras.

📱 Download do aplicativo

Você pode baixar e instalar a versão APK para Android diretamente pelo Google Drive:

👉 "Baixar Lista de Compras (.APK)" (https://drive.google.com/file/d/1urAjjWnBO6sxlOQGy72nshptIQrTWxL8/view?usp=drivesdk)

«⚠️ Observação: como o aplicativo está sendo distribuído diretamente em formato APK e ainda não está publicado na Google Play Store, o Android poderá solicitar autorização para instalar aplicativos de fontes externas.»

✨ Funcionalidades

- 🛒 Criar e gerenciar listas de compras
- ➕ Adicionar produtos à lista
- ✅ Marcar produtos como comprados
- ❌ Remover produtos
- 📋 Visualizar facilmente os itens da lista
- 💾 Manter os dados salvos no dispositivo
- 📱 Interface simples e intuitiva
- 🚀 Aplicativo desenvolvido para Android

🎯 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de criar uma solução simples para uma necessidade do dia a dia: organizar as compras de forma rápida e prática pelo celular.

Além de ser uma aplicação funcional, o projeto também faz parte do meu processo de aprendizado e evolução no desenvolvimento de aplicativos mobile.

🛠️ Tecnologias utilizadas

O aplicativo foi desenvolvido utilizando:

- React Native
- Expo
- JavaScript / TypeScript
- AsyncStorage
- Android
- EAS Build

📲 Instalação

1. Baixe o arquivo ".apk" pelo link acima.
2. Abra o arquivo no seu celular Android.
3. Caso seja solicitado, permita a instalação de aplicativos de fontes desconhecidas.
4. Instale o aplicativo.
5. Abra o Lista de Compras e comece a utilizar.
